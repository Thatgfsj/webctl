## 约定

- 文件名：`NNNN-短横线标题.md`，编号不复用。
- 结构：状态 / 关联 / 背景 / 决策 / 备选方案 / 后果 / 证据。
- 修改历史决策**不改旧文件**：新开一条 ADR，并在旧条目上标"被 ADR-XXXX 取代"。
- ADR 只记决策，不夹带实现细节；实现写在代码与 PR 里。
